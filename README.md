# نور الإسلام - تطبيق إسلامي شامل

تطبيق ويب إسلامي متكامل بواجهة عربية احترافية متجاوبة مع الهواتف، مبني بلغة Python (Flask) + HTML + CSS + JavaScript.

## المميزات

- **القرآن الكريم**: كل السور الـ 114 مع بحث سريع، وتلاوة صوتية كاملة لـ 8 من عمالقة القراء (العفاسي، عبد الباسط، الحصري، المنشاوي، ماهر المعيقلي، سعود الشريم، عبد الله بصفر، محمد أيوب).
- **التلاوات المميزة**: قسم خاص بالمشايخ الكبار وتلاوات مختارة (سورة الملك، الكهف، يس، الرحمن، آية الكرسي، المعوذتين).
- **الأحاديث النبوية**: من صحيح البخاري، مسلم، الترمذي، النسائي، ابن ماجه - مع شرح مختصر لكل حديث.
- **الأذكار**: أذكار الصباح والمساء بتفاصيلها (النص، عدد التكرار، المرجع، فضل الذكر)، أذكار الاستيقاظ، النوم، الطعام، دخول الخلاء - مع عداد تفاعلي وشريط تقدّم واهتزاز عند الإكمال.
- **درس كل يوم**: آية من القرآن + حديث نبوي يتغيران يومياً تلقائياً.
- **مواقيت الصلاة**: حسب المدينة مع التاريخ الهجري وتنبيه قبل الصلاة بعشر دقائق.
- **نظام الإشعارات**: تذكير بأذكار الصباح والمساء، الصلاة على النبي كل ساعة، ذكر الله كل ساعتين، تنبيه الصلاة - عبر إشعارات المتصفح.
- **الألعاب والغاز**: أسئلة دينية تفاعلية (15 سؤالاً)، لعبة ذاكرة بالأيقونات الإسلامية، ولغز ترتيب الحروف.

## التشغيل

```bash
pip install -r requirements.txt
python app.py
```

ثم افتح المتصفح على `http://localhost:5000`

## المتطلبات

- Python 3.8+
- اتصال بالإنترنت (للتلاوات الصوتية ومواقيت الصلاة)
- متصفح حديث يدعم إشعارات الويب
